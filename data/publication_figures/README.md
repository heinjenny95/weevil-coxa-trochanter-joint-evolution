# Final publication figures

This directory contains the 38 final raster figures embedded in the regular
manuscript: five main figures, six Extended Data figures and 27 Supplementary
figures. `figure_manifest.csv` records the stable repository path, file size,
pixel dimensions and SHA-256 checksum for each PNG. `figure_alt_text.csv`
provides a stable title and scientific text alternative for every figure.

The files are versioned source assets for provenance and document assembly.
Where a figure is generated by a released analysis script, the corresponding
renderer and plotting inputs remain the reproducible source; image-only
photographic or manually assembled panels are preserved here as final assets.

The alternate black-background draft of main Figure 3 is not part of this
release. It remains only in the dated project backup.
